# Privacy Policy — DualTran for Obsidian

DualTran for Obsidian translates text you explicitly select or the note you
explicitly translate. It collects **nothing**: no analytics, no telemetry, no
accounts, and no developer server exists.

- Text you translate is sent to the translation service **you** selected:
  Google (default, no account needed) or, if you configure AI mode, directly
  to your AI provider using **your own API key**.
- Settings and your API key are stored locally in this vault's plugin data.
  Uninstalling the plugin removes them.
- No other network requests are made.

Bundled engine: `@dualtran/core` (MPL-2.0), extracted from
https://github.com/seigwen/DualTran-extension.
